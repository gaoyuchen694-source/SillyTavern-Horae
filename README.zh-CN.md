> *Horae（荷赖）— 希腊神话中掌管时序的女神*

长篇 RP 玩家的老毛病你一定遇到过 —— AI 的记忆约等于金鱼：昨天的事说成今天早上，连几天前发生的事都永远说是昨天；上一幕穿校服下一幕突然便服；NPC关系倒置；送出去的礼物凭空消失，丢掉的东西又回到手里。

**Horae 用结构化的时间锚点，给你的 AI 装上一本靠谱的记忆账本。**

---

## 亮点功能

**同日权威记忆 —— 下午仍记得上午发生的事**
当天所有有效事件会进入独立的同日记忆账本，不受普通时间线深度、摘要隐藏或向量阈值影响。主线故事时钟会隔离闪回，并对没有剧情依据的时间倒退给出异常提示。

**叙事日历与生命周期 —— 时间过去，世界也会变化**
日历按剧情日期汇总事件、计划、物品变化与时间异常，支持公历、自定义历法和无法换算为月份的奇幻日期。计划会完成、取消、逾期或归档；`dueAt` 只表示计划/截止时间，跨到第二天不会清除安排在几天后的计划，逾期后也会继续保留为 `overdue`。物品支持数量变化、转移、消耗、到期和按日递减，不再无限堆积。

**RPG 模式 —— 血条、技能、声望、装备、等级、货币一目了然**
为西幻 / 修真 / 战斗向角色卡量身打造的全模块化 RPG 系统。各子系统（属性条、多维属性、技能、声望、装备、等级、货币）均为**独立可选开关**，按需组合。角色卡内信息采用**标签分页**展示（属性/技能/装备/声望/等级/货币），仅显示已开启的模块，节约空间。**声望系统**支持自定义势力分类和数值范围。**装备系统**支持自定义格位与属性值追踪。**等级系统**追踪角色等级和经验值，经验条进度可视化。**货币系统**支持自定义币种和兑换比率（如 1000铜=10银=1金），AI 可通过增量或绝对值修改。所有配置均可导出/导入 JSON。关闭时不注入提示词、不消耗 Token。

**向量记忆引擎 —— 找回被折叠的细节**
专为搭配「自动摘要&隐藏」设计的智能外脑！几十万字长篇压缩后细节全丢？现在当对话触及历史事件时，插件会自动从被隐藏的旧时间线中精准召回相关片段。全程依托 Web Worker 纯本地运算，零 API 消耗，丝滑不卡顿界面（首次运行需下载 30-60MB 模型缓存，提供中文优化的 bge 和多语言 e5 双模型可选⚠ 2GB 以下手机或云酒馆建议別用）。

**新手导航 —— 第一次用也不迷路**
首次使用 Horae 的用户会自动触发交互式导览，逐步介绍各功能区域和设置项。

**自助美化工具 —— 不会写 CSS 也能自定义**
为不会写代码的用户设计的可视化美化面板。用色相条、饱和度/亮度滑杆快速调色，日夜模式一键切换，还能导入图片 URL 装饰抽屉头部、背景和底部消息栏。（⚠️做 Horae 插件的美化不用跟我要授权，请随意。）

**场景记忆 —— 酒馆不再一夜变样**
AI 描写同一个地点，上一回有壁炉这一回没了？场景记忆会记录地点的固定物理特征，下次进入同一场景时自动注入。

**情绪 & 关系网络 —— AI 读懂人际场**
情绪追踪让 AI 记住角色当前的心理状态，不再前一秒哭后一秒笑。关系网络记录人物之间的关系类型和变化。

**自动摘要 —— 长篇自动省 Token**
聊了几百楼还在全量发送？自动摘要在后台自动压缩旧消息为一段摘要，原始楼层 `/hide` 省 Token。

**辅助 API —— 后台任务不抢主 API**
可为 AI 分析、底部栏/楼层魔术棒、发送前补全、自动总结、AI 智能补全、手动多选压缩单独配置 OpenAI 兼容端点。辅助 API 请求会串行排队，降低副端点并发限流风险；API 地址、密钥、模型不会随 Horae 配置档导出。

**告别"永远的昨天"** · **衣服不再乱穿** · **NPC 不会越写越糊** · **物品栏终于靠谱了** · **待办事项防遗忘** · **自定义表格** · **变化驱动省 Token** · **截断/改写也不怕**

## 快速安装

1. 打开 SillyTavern → 顶部扩展面板（积木图标）→ 「安装扩展」
2. 粘贴 `https://github.com/gaoyuchen694-source/SillyTavern-Horae.git`，点击安装
3. 安装完成后刷新页面即可使用

> 配套正则会在插件首次加载时**自动注入**，无需手动导入。

---

## 从原版 Horae 升级

原版 Horae 聊天数据可以直接使用。用本仓库替换原版扩展、刷新 SillyTavern 后，重新打开原来的聊天即可。新版记忆引擎会自动重放现有 `horae_meta`、`item`、`item-`、`agenda` 和 `agenda-` 数据，**无需导出、迁移按钮或重新扫描全部历史**。

替换扩展前建议备份重要聊天。增强版保留了原扩展目录与数据格式以实现直接兼容，请不要同时重复安装原版仓库和增强版仓库。

## v1.17.1 更新内容

### 叙事日历优化

- **日历与事件页分离**：日历不再重复展示总结或跨段回顾，事件时间线仍完整显示总结卡片。
- **关键事件优先**：每日默认展示最多 6 条关键/重要事件，其余记录可展开查看，并合并同日高度相似事件。
- **变化更完整**：日历新增地点与关系变化，继续保留计划、物品和时间异常。
- **数据与 AI 注入不变**：筛选只在日历运行时生效，不改写聊天元数据，也不改变发送给 AI 的总结、同日记忆或向量召回。

## 公开 API（供其他扩展 / 预设脚本调用）

Horae 加载完成后，会在 `window.Horae` 上暴露只读 API：

```js
// 判断 Horae 是否已安装且启用
window.Horae?.isEnabled()        // → true / false

// 读取当前世界状态（时间、地点、在场角色、服装、物品、情绪、NPC……）
window.Horae?.getLatestState()   // → state 对象

// 读取时间线事件
window.Horae?.getEvents(10)      // → 最近 10 条事件

// 读取设置（浅拷贝）
window.Horae?.getSettings()

// 版本号
window.Horae?.version            // → "1.17.1"
```

设置变更事件通过酒馆的 `eventSource` 广播：

```js
eventSource.on('horae:settingsChanged', (data) => {
    console.log('Horae enabled:', data.enabled);
});
```

> 所有方法均为**只读**，不暴露任何写入操作。
